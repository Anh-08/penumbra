# Penumbra demo storyboard (3 minutes)

Paced replay of the recorded `fault-storm` run. The judge's Approve is the only required click (T35). Times are wall-clock from the moment a judge stops.
Order as recorded and replayed by the demo director (T35): SAT-12 (Tier 1, auto), then SAT-07 (Tier 2, the judge's Approve), then SAT-19 (infeasible, SAFE_MODE recommended), then fast-forward and reveal. Paced replay measured at 90.6 s with Approve pressed at once; the approval pause stretches as long as the presenter talks.
Spoken lines contain no result numbers. Every number the judge sees comes from the screen.

## Fallbacks
- WebSocket drop: last state stays on screen with `RECONNECTING · showing last state` badge; presenter keeps talking over frame 5's matrix.
- Run live: the small `run live` toggle in the FD bar switches the next run to Gemini; the top bar mode chip changes from `REPLAY` to `LIVE · Gemini`. Use only if a judge asks "is this real?".
- If a judge walks up mid-demo, point at the stepper: the active stage tells them where we are.
